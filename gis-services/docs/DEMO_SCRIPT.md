# Member 4 Demo Script

1. "This is our GIS module. It answers two questions: where did the spill come from, and where will it go?"

2. "First, we take the detected spill point and run the drift model backward using environmental conditions. For SP101, the estimated origin is 15.201 N, 73.512 E at 23:40 UTC on August 28."

3. "The cyan polygon represents uncertainty. Our demo confidence is 81% with ±12 km uncertainty."

4. "Next, we take that origin and forecast the movement for 72 hours."

5. "The orange path shows the predicted drift, with markers at +24, +48 and +72 hours."

6. "The important point is that we expose confidence and uncertainty rather than presenting the prediction as certain."

7. "This is a baseline advection model for the MVP; real deployment can replace the mock environmental data with validated live products."
